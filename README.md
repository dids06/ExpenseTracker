# Expense Tracker (CLI)

A simple command-line based expense tracker built using Python.  
This application allows users to record their expenses and view spending details directly from the terminal.

---

## Features
- Add new expenses
- View all recorded expenses
- View total amount spent
- Menu-driven command line interface
- Handles basic invalid input

---

## Tech Stack
- Python

---

## How It Works
1. The program displays a menu with available options.
2. The user selects an option by entering a number.
3. Expenses are added by entering an amount and a description.
4. All expenses are stored while the program is running.
5. The program continues until the user chooses to exit.
